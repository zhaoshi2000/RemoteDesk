# v0.2 安全边界

设备 Ed25519 私钥仅存在本机受保护状态中。服务器保存公钥，但服务器被入侵并不因此获得设备私钥；设备仍须通过本机 ACL 授权并通过 QUIC/TLS 私钥持有证明。媒体认证不依赖从不可信服务器自动下载一个公钥并相信它。

控制、剪贴板、音频和文件按能力授权。主机在交互用户会话中可见，断开/撤销/父进程退出释放按键。Session 0 的桌面捕获被拒绝，SYSTEM 服务不执行用户媒体程序。没有隐蔽控制、UAC 关闭或自动加入不可信公钥。

QUIC 实现限制证书/帧/流/队列大小。视频流可以过期取消；可靠键鼠通道发生截断/溢出应断开而不是悄悄丢键。中继只能转发加密包。跨公网地址验证、网络迁移和所有实现的独立安全审计仍需要实际验证。

文件根目录和暂存目录须为当前用户专用。已有路径校验、符号链接/重解析点拒绝、文件哈希及大小限制，但路径检查与系统打开之间仍存在本机恶意写入者的竞态边界，不能把它作为任意共享目录的安全沙箱。

内嵌 SSH 只运行本地 OpenSSH，不执行字符串拼接 shell 命令。ConPTY 输入/输出独立线程、有界队列，WebEngine 仅加载应用终端资源，网页无通用文件读写或系统命令桥。SSH 输出本身是不可信数据；保持 Qt/xterm/OpenSSH 依赖及时更新。

管理端有角色授权、Secure HttpOnly SameSite cookie、Origin 校验与会话上限。新增令牌只返回一次，服务器保存哈希。禁止公开 state/令牌/生产私钥。审计日志不记录 SSH 内容、终端输入或设备私钥。

发布签名验证和安全暂存不等于完整安全更新体系；自动激活、回滚、密钥轮换、权限隔离与端点威胁模型仍需补齐。发布前进行代码安全审查和真实设备权限测试。
