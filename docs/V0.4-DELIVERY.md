# RemoteDesk 0.4 图形客户端与设备状态

## 两个产品

服务端 `RemoteDesk-Server-linux-amd64.tar.gz`；Windows 客户端 `RemoteDeskSetup.exe`。
Qt、Agent、Rust Quinn、FFmpeg/Opus、终端资源、Windows 官方 VC++ 运行库均由安装器统一处理，不分别分发为产品。

## Windows 使用顺序

1. 安装客户端，打开 RemoteDesk 图形界面。
2. “初始化 / 注册”：填服务端 HTTPS 地址、STUN 地址（通常 域名:3478），选择公开 `server.crt` 和私密的注册令牌文件。不得复制服务端私钥。
3. 点击“启动 / 停止主机”启动本次登录用户的 Agent。顶栏分别显示服务端可达和本机进程状态，实际在线由服务端心跳确认。
4. 两台机器通过可信渠道核对公钥指纹，导出公钥并“添加可信设备”。被控方选择控制方 ID，在“共享权限”单独授予桌面、键鼠等能力；在“本机托管设置”明确启用桌面。
5. 输入远端 ID 后连接桌面、SSH 或文件。SSH 仍使用 Windows/OpenSSH 账号及密钥，不以设备信任替代用户认证。

没有公共默认远控口令，不实现伪造临时验证码。用户名、服务器地址保存在配置中；设备私钥由 DPAPI 保护。界面记住配置目录和最近设备 ID，不缓存注册令牌。

## 客户端界面

设备连接、远程桌面、文件传输、诊断日志、本机信息五个页面；SSH 以独立终端标签打开。提供设备 ID 复制、注册向导、公钥导入、权限设置、连接参数、全屏、文件进度、日志导出、打开管理后台。

## 管理后台新增信息

设备详情：系统版本、架构、CPU、逻辑核心、物理内存、GPU/驱动、Windows CIM 当前显示配置、Agent 版本、进程运行时间、CPU/内存/所在卷采样、进程 RSS、主机 IP、服务器观察来源 IP、候选地址、公钥指纹、最后心跳/报告时间、桌面/文件配置、媒体程序是否存在、SSH 回环 TCP 端口是否可连接。

来源说明：只有 HTTPS 对端地址和接收时间由服务器观察。硬件和资源是经设备身份签名的报告，不是硬件真实性证明。媒体程序存在不代表 GPU 编码成功，SSH 端口可连接不代表成功登录，CIM 显示配置不是完整显示器枚举。

上报默认每 15 秒一次；在“本机托管设置”关闭状态上报并重启主机进程可停用。字段不包括屏幕、剪贴板、文件列表、私钥或账号口令。已注册且未禁用设备才能上报，不能指定别人的设备 ID。

45 秒未收到报告标为过期。服务器内存保存每设备最近 40 次采样，最多 2048 台报告设备；1 小时无新报告清理。服务器重启后重新上报，不是长期持久监控数据库。旧客户端显示“未上报”；API 不可达显示“状态未知”。Windows 网卡吞吐、实际 NAT 分类、直连 P2P 媒体性能遥测仍未接入。

## 验证边界

构建流程包含 Go、Rust、C++ 测试，真实浏览器 Admin 检查，Qt 窗口/导航截图，安装器静默安装与清理开发 PATH 后的启动检查。只有实际执行成功的记录才写入交付证据；源码中配置了测试不等于测试已通过。

两台 Windows 的 GPU 端到端视频、键鼠/音频联合运行、跨公网 NAT 矩阵、1080p60/低延迟、无人值守跨用户会话及安全桌面没有由这些界面测试替代。当前是预览工程版，不提供这些性能和兼容性达标声明。Windows 安装器未使用你的代码签名证书签名。

## 运行库及许可证

VC++ 运行库由微软官方链接下载并检查 Authenticode 签名；Qt 动态部署，第三方版权文本随包附带。实际运行库版本及 SHA-256 记录在 `docs/VC-RUNTIME.json`。
