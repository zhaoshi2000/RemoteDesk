# 0.3 控制台与两个产品包

恢复此前已上传但未挂到 main 的工程源代码，并在保留其 Qt、Rust、设备协议、签名版本与用户角色模型的基础上整合管理后台。没有把旧附件中的不同媒体协议覆盖到恢复的客户端上。

新增：真实 Linux 资源采样、启动就绪组件状态、5 秒在线检测、数据过期处理、设备分组/别名/备注、注册开关、10 个 Vue Admin 页面、用户权限、CSRF/登录限流、失败写入回滚。

打包：服务端将 Vue 静态资源嵌入 Go 可执行文件；客户端只打一个 Setup，不再单独发布 Agent、DLL、测试程序。安装脚本不自动覆盖已有密钥、不关闭防火墙。

本地已执行根 Go 模块测试、race、Linux/Windows vet、7 项前端状态逻辑测试、Linux CMake Release 构建和原生测试。根 Go 测试不包含 Rust 或 Windows GPU。完整 Vue 构建及 Windows 安装器的结果以本次 Actions 实际记录为准；不得据此把 Windows 性能标为已验收。
