# v0.2 状态与验收边界

本文件的“源码实现”不是 Windows 实机运行声明。最终编译和测试结果以对应提交的 Actions 日志为准。

| 模块 | 本次源码/本地状态 | 尚需验证或实现 |
|---|---|---|
| 注册/心跳/签名/SSH | Go 回归测试通过，保留 v0.1 | 真实 sshd/安装行为 |
| 媒体授权/UDP 中继/路径回退 | Go 测试通过 | 跨运营商 NAT、公网链路迁移 |
| Rust/Quinn | 双向公钥认证、帧/控制流、有界队列、C ABI 已实现 | Actions 编译测试；不得与 OpenSSL 测试混称 |
| OpenSSL 3.5 QUIC | 实际 UDP 双向认证、256 KiB 帧、输入、错误公钥拒绝测试通过 | Windows 互操作/弱网 |
| DXGI GPU 采集/色彩转换 | 源码连接 GPU 纹理路径 | Windows/GPU 编译和实机 |
| NVENC/QSV/AMF | FFmpeg 三后端选择、低延迟 H.264 编码实现 | 各厂商驱动实机 |
| D3D11 硬解/渲染 | GPU 表面解码、VideoProcessor、swapchain 实现 | Windows 交互桌面 |
| 输入/光标/剪贴板 | SendInput、分通道、释放按键、文本循环抑制实现 | 不同 DPI、键盘布局、特殊光标 |
| 音频 | WASAPI loopback、Opus、独立流实现 | 延迟、设备切换、持续 A/V 同步 |
| 文件 | 独立授权 TLS 通道、限速、断点、覆盖确认、SHA-256；Go 测试通过 | 非 QUIC 文件通道；目录下载/空目录/高并发不足 |
| Qt/内嵌 SSH | Qt UI + ConPTY + xterm.js 源码完成 | Windows 构建、终端交互和窗口寿命测试 |
| Vue 管理后台 | 真实 API 接入，Go 管理认证测试通过 | 前端类型检查/浏览器；节点仅管理元数据 |
| PostgreSQL/Redis | 可选后端和 Docker 部署文件实现 | 真实集成测试；信令会话仍单进程 |
| Windows Service | 身份/SSH 可用代码，禁止 SYSTEM 执行用户媒体配置 | 未实现 WTS、安全桌面、登录前画面 |
| 签名更新 | 验签、过期/降级拒绝、安全暂存通过单元测试 | 自动激活、运行中服务替换、恢复回滚未实现 |
| 安装包 | 完整目录 Inno Setup 源码和构建脚本 | 产物见 Actions；安装/卸载尚未实机验收 |
| 性能 | 有真实统计输出，不虚构 FPS/延迟 | 1080p60/2K/4K/120FPS 全部未做实机性能验收 |

所有缺口都保留在表中；不得把“源码有模块”理解为“全部需求已完成”。原始 v0.1 报告另存历史文件，不作为 v0.2 测试结果。
